# Interfaz Grafica de Tkinter
Este proyecto es una calculadora básica implementada con Tkinter, el módulo estándar de Python para crear interfaces gráficas de usuario (GUIs). La calculadora permite realizar operaciones aritméticas básicas como suma, resta, multiplicación y división. También incluye un botón para limpiar ("C") y otro para obtener el resultado de las operaciones ingresadas ("=").


## Descripción del Proyecto
El objetivo principal de este proyecto es demostrar cómo usar Tkinter para crear una interfaz gráfica sencilla que interactúa con el usuario. La calculadora está compuesta por:

Un cuadro de entrada que muestra las operaciones y los resultados.
Botones con números y operadores que permiten al usuario ingresar los cálculos.
Manejo de errores mediante un mensaje emergente si se ingresa una operación inválida.


### Cómo Ejecutar el Proyecto
Asegúrate de tener instalada la versión 3.x de Python.
Ejecuta el archivo calculadora.py desde la terminal o un entorno de desarrollo (IDE) como VSCode o PyCharm:
``` 
python calculadora.py
```
